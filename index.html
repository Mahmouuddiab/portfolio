# Overview

Mahmoud Diab is a Flutter developer and mobile engineer with 4+ years of experience across Egypt and Saudi Arabia, building clean, scalable, and high-performance mobile applications end to end — from architecture down to the pixel.

Most days are spent inside Clean Architecture, wiring up state with Riverpod, Bloc, and Cubit, and getting Firebase and Supabase to behave in production, not just in the emulator. Recent focus has shifted toward shipping infrastructure: CI/CD pipelines, notification lifecycles, and the small, unglamorous bugs that decide whether an app actually feels reliable.

Comfortable working across Arabic and English, RTL and LTR, and just as comfortable debugging a state provider at midnight as sketching a new onboarding illustration for the next release.

CORE

Clean Architecture & State Management

Cubit/BLoC, Provider, and Riverpod, applied with SOLID principles across production codebases.

SHIP

Firebase & Supabase-Backed Systems

Auth, Firestore, FCM, Storage, and Cloud Functions wired into real-time chat, notifications, bookings, and search.

SCALE

GitHub Actions pipelines — test, build, deploy — with Firebase App Distribution for QA builds.

NEXT
